# Urlaubsbudget

Eine einfache Single Page Anwendung zur Verwaltung von Reisebudgets.

## Funktionen

* Mehrere Konten oder Personen verwalten
* Automatische Berechnung des verfügbaren Tagesbudgets
* Erfassung von Ausgaben je Konto
* Speicherung aller Daten lokal im Browser via LocalStorage
* Mobilfreundliches Design ohne externe Abhängigkeiten

## Nutzung

Datei Urlaubsbudget.html im Browser öffnen.

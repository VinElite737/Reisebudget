# Urlaubsbudget (PWA)

Alle Dateien liegen flach im Hauptordner, ohne Unterordner:
index.html, manifest.json, sw.js, icon-192.png, icon-512.png,
icon-maskable-512.png, apple-touch-icon.png, icon.svg, .nojekyll

1. Neues GitHub-Repository anlegen und ALLE Dateien hochladen (auch .nojekyll).
2. Settings -> Pages -> Branch main, Ordner / (root) -> Save.
3. Adresse auf dem Handy in Chrome oeffnen, 1-2x neu laden, dann Menue -> "App installieren".

Update ausrollen: in sw.js CACHE_NAME auf v2, v3 ... hochzaehlen.
